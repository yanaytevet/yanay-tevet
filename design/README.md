# design/

Working files for the design system. The spec itself is `../DESIGN.md` — this folder is how we got there
and what is left.

| File | What it is |
|---|---|
| `audit.md` | The October 2026 audit of the frontend against the design system: every inconsistency found, with counts and where it lives, and whether it is fixed. |
| `roadmap.md` | The rounds of work: what each round covers, what is done, what is next. |

When a round finishes, update the status columns in both files; when the spec changes, change `DESIGN.md`,
not these.
